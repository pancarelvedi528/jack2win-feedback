# Jack2Win Feedback / Comentarios de Jack2Win

[Website / Sitio web](https://jacktowin.com/) · [English guides](https://jacktowin.com/) · [Guías en español](https://jacktowin.com/es/)

## English

Jacktowin.com is the official Jack2Win game guide, available in English and Spanish. It explains game controls, rules, and features.

This public repository collects Jack2Win problems, website corrections, and suggestions for improvement.

### Share feedback

- [Browse and search existing issues](https://github.com/pancarelvedi528/jack2win-feedback/issues)
- [Report a problem](https://github.com/pancarelvedi528/jack2win-feedback/issues/new?template=01-bug.yml)
- [Suggest an improvement](https://github.com/pancarelvedi528/jack2win-feedback/issues/new?template=02-suggestion.yml)
- [Other feedback](https://github.com/pancarelvedi528/jack2win-feedback/issues/new/choose)

Before opening an issue, search for an existing report. If you find the same problem, add useful details there. Otherwise, open a new issue in English or Spanish and describe what happened, how to reproduce it, and what you expected. Include the affected page, device, and browser when relevant.

Issues and attachments are public. Remove personal information from screenshots. Do not post passwords, verification codes, identity documents, payment details, or private account information. For private account or payment matters, use the support channel within the platform you use.

## Español

Jacktowin.com es la guía oficial de juegos de Jack2Win, disponible en inglés y español. Explica los controles, las reglas y las funciones de los juegos.

Este repositorio público reúne problemas relacionados con Jack2Win, correcciones del sitio web y sugerencias de mejora.

### Envía tus comentarios

- [Consulta y busca reportes existentes](https://github.com/pancarelvedi528/jack2win-feedback/issues)
- [Informa de un problema](https://github.com/pancarelvedi528/jack2win-feedback/issues/new?template=01-bug.yml)
- [Propón una mejora](https://github.com/pancarelvedi528/jack2win-feedback/issues/new?template=02-suggestion.yml)
- [Otros comentarios](https://github.com/pancarelvedi528/jack2win-feedback/issues/new/choose)

Antes de abrir un reporte, busca si el problema ya se ha comunicado. Si encuentras el mismo problema, añade allí los detalles útiles. De lo contrario, abre un nuevo reporte en inglés o español y explica qué ocurrió, cómo reproducirlo y qué esperabas. Incluye la página afectada, el dispositivo y el navegador cuando corresponda.

Los reportes y archivos adjuntos son públicos. Elimina los datos personales de las capturas de pantalla. No publiques contraseñas, códigos de verificación, documentos de identidad, datos de pago ni información privada de tu cuenta. Para asuntos privados de cuenta o pagos, utiliza el canal de soporte de la plataforma que usas.
